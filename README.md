# Job Portal app
Now design a react app to create and visualize job posts based on the files. After that, you need to use the given API endpoints and apply CRUD operation.

## API Endpoints:
1. Create jobs And View jobs  (Allowed: POST, GET. required to pass access token key)
2. Edit/Remove job(Allowed: PUT, PATCH, DELETE)
3. Sign_up user(Allowed: POST)
4. Sign_in user (Allowed: POST)

## Installation
### Client Side

1. Clone the repository
2. Run ```cd client``` to go into the client directory
3. Setup the environment variables in the example.env file (rename the file to .env.local)
4. Run ```npm install``` in the root directory to install all the dependencies
5. Run ```npm install --force``` if you get any errors
6. Run ```npm start``` to start the client

### Server Side

1. Run ```cd server``` to go into the server directory.
2. Run ```npm install``` install dependencies.
3. Run ```npm start``` to start the server.

   
## Features
1. User can register and login
2. User can view all the jobs
3. User can view a single job
4. User can delete a job
5. User can create a job
6. User can update a job
